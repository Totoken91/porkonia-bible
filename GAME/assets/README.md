# Assets GAME

Ici, ChatGPT (ou Kenny) dépose les **images de référence** dont Claude et ChatGPT ont tous deux besoin pour rester cohérents.

- `refs/` : les 16 portraits de référence, nommés `ref-01-steeve-carrie.png` … `ref-16-colette-marsan.png` (liste dans `GAME/prompts/images-chatgpt.md`, partie A).
- Tous les fichiers GAME commencent par `game-` ou `ref-`.
- Pas de photos réelles de collègues qui ont refusé, pas de Douzi.
- Seulement les références : les images finales du jeu vont dans le dépôt du jeu (`porkos-game`), pas ici.
- Poids conseillé : moins de 2 Mo par image.
