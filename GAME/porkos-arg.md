# PorkOS et l'ARG

## PorkOS et l'ARG

**PorkOS est la porte d'entrée du jeu.** C'est le système d'exploitation officiel de la République, jouable dans le navigateur. En surface, c'est un OS d'État ringard et drôle. En profondeur, c'est un poste qui contient des choses qu'il ne devrait pas contenir.

**Comment les médias s'emboîtent**

| Média | Rôle dans l'ARG |
| --- | --- |
| Porkopédia | La version officielle. Le joueur y vérifie les faits, et repère ce qui a été effacé ou modifié |
| PorkOS | Le terrain de fouille : dossiers, mails, logiciels d'État, corbeille, fichiers corrompus |
| Channel Pork | La propagande et la culture populaire, où se glissent des images qui ne collent pas |
| Radio Viteau | Diffusion continue ; un jingle, un bruit ou un blanc peut être un indice |
| Footage | Les preuves brutes, retrouvées dans PorkOS ou publiées ailleurs |

**Principes de design (propositions)**

- Tout ce qui est dans PorkOS est un objet du monde, pas une interface de jeu : pas de barre d'XP, pas de tutoriel qui parle au joueur.
- Les indices se recoupent entre médias : un nom dans un mail PorkOS renvoie à une notice Porkopédia qui dit autre chose.
- Les contradictions entre sources sont voulues et consignées dans le journal (statut « Mensonge d'État » ou « Archive altérée »).
- Chaque découverte récompense par de la Surface drôle ET un pas vers le Fond.

**Direction visuelle de PorkOS : à décider avec l'auteur.** Pas de Windows XP par défaut. Pistes à comparer : OS administratif ivoire et bordeaux dans l'esprit des documents d'État ; OS de terminal de brasserie, vert sur noir, bricolé ; OS grand public de 2002 fait par une administration qui a mal copié les autres.

**Le spin-off déjà envisagé :** PorkOS devient l'ordinateur d'un personnage, qu'on fouille pour enquêter.

**Questions qui décident de toute la structure**

- [ ] Qui est le joueur ? Quelqu'un qui récupère un vieux PC porkonien, un fonctionnaire, un technicien Econopork, un enquêteur étranger ?
- [ ] À qui appartient le poste qu'on fouille ?
- [ ] Le Fond a-t-il une origine unique à révéler ?
- [ ] Format : jeu fini avec une fin, ou ARG vivant qui évolue en ligne dans le temps ?
